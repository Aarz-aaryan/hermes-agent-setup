# Axolotl

Axolotl LLM fine-tuning framework.

## Setup

```bash
pip install axolotl
```

## Usage

```yaml
# axolotl config
model:
  name: meta-llama/Llama-2-7b
```

## Features

- Multi-model support
- DeepSpeed integration
- FSDP support
