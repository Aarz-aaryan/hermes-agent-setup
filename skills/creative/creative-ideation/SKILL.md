# Creative Ideation

## Concept
Generate creative ideas using constraints. Constraints are not limitations — they are the spark that ignites creativity.

## How It Works
1. Present a domain or problem
2. Apply a constraint (random word, number, format, etc.)
3. Generate 5-10 ideas that satisfy the constraint
4. Optionally combine the best ones

## Constraint Types

### Random Word
Take a random word from: book, fire, water, shadow, clock, mirror, key, door

### Number Constraint
Pick a number 1-100. All ideas must somehow incorporate that number.

### Format Constraint
- "3 words or less"
- "a tweet (280 chars)"
- "a haiku"
- "a single image prompt"

### Combination Constraint
Take two unrelated concepts and force a connection.

## When to Use
- Blank page syndrome
- Need fresh angles on a problem
- Building something and want unexpected features
- Creative briefs, naming, branding

## Output Format
```
## Ideas (constraint: <constraint>)

1. <idea>
2. <idea>
...

### Top Pick
<pick the single best and explain why>
```
