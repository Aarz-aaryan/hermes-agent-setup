# Systematic Debugging

A methodical approach to debugging software issues.

## Steps

1. **Reproduce** - Get reliable reproduction case
2. **Isolate** - Narrow down the cause
3. **Hypothesize** - Form theories about cause
4. **Test** - Verify hypotheses
5. **Fix** - Apply and validate fix

## Tools

- Debuggers (pdb, gdb, lldb)
- Logging and tracing
- Profiling tools
