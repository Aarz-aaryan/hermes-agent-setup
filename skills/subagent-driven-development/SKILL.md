# Subagent-Driven Development

A development approach where specialized sub-agents handle different aspects of a project.

## Architecture

- Supervisor agent coordinates
- Specialized sub-agents for domains
- Shared context and memory

## Best Practices

- Clear task boundaries
- Regular sync points
- Quality gates between agents
